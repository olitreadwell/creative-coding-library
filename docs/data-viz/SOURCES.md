# Data Sources

Where datasets come from. Commercial-friendly first.

## Row A — Public domain / CC0 (paid-gig-safe)

- data.gov (US federal) — most CC0 / public domain
- data.govt.nz (NZ) — CC-BY-4.0 by default
- Kaggle datasets marked CC0 — verify per dataset
- Awesome Public Datasets (awesomedata/awesome-public-datasets) — index, license per source
- Wikidata — CC0 for data, attribution courtesy

## Row B — CC-BY (paid-gig-safe with attribution)

- Our World in Data — CC-BY-4.0
- World Bank Open Data — CC-BY-4.0
- NASA open data — most public domain or CC-BY
- Eurostat — varies, mostly CC-BY-4.0

## Row C — Government / agency APIs (check per endpoint)

- NIWA, Stats NZ, Te Whatu Ora (NZ)
- UK gov data, TfL Open Data (Transport for London — free with API key, attribution required)
- Census Bureau (US)
- OECD

## Row D — ODbL / NC / opt-in (`personal-only` only)

- OpenStreetMap — ODbL (share-alike for derived data; commercial-OK but the derived data must also be ODbL)
- Some Kaggle datasets — varies
- Most scraped datasets without explicit license — treat as ODbL or worse

## Row E — Avoid

- Datasets without license header that scrape closed sites
- TOS-restricted APIs (most social platforms)
- Datasets requiring API keys gated by paid agreements
