## How it works, step by step

This app simulates a flock using plain TypeScript and a Canvas 2D draw loop. No physics engine. No special library. Here is the full idea, broken into small pieces.

### Step 1: create the flock

Each boid starts at a random position with a random velocity. Velocity is a 2D vector: `vx` is speed left-right, `vy` is speed up-down. We seed the random number generator so the same seed always produces the same starting flock.

```ts
type Boid = { x: number; y: number; vx: number; vy: number };

function makeBoids(rng, count, width, height): Boid[] {
  // ...
  const angle = randRange(rng, 0, TAU); // random heading
  const speed = randRange(rng, minSpeed, maxSpeed);
  boids.push({
    x: randRange(rng, 0, width),
    y: randRange(rng, 0, height),
    vx: Math.cos(angle) * speed,
    vy: Math.sin(angle) * speed,
  });
}
```

### Step 2: look at neighbours

Every frame, each boid scans all other boids. It only cares about boids inside its **perception radius** — a circle around itself. Boids outside that radius are invisible to it.

### Step 3: apply three steering rules

For each boid, we gather information from its visible neighbours, then apply three forces.

```ts
// Separation: neighbours that are TOO close push this boid away.
//   Weight: inversely proportional to distance, so closer = stronger push.
sepX -= dx / dist;

// Alignment: steer toward the average velocity of neighbours.
newVx += (avgNeighbourVx - b.vx) * alignmentWeight * 0.05;

// Cohesion: steer toward the average position of neighbours.
newVx += avgNeighbourDx * cohesionWeight * 0.001;
```

The small multipliers (0.05, 0.001) stop any one rule from overpowering the others. Tuning these numbers changes how the flock behaves.

### Step 4: limit speed and wrap the edges

After applying all three forces, the new velocity might be too fast or too slow. We clamp it to `[minSpeed, maxSpeed]`. Then we move the boid by its velocity and wrap it at the canvas edge — a boid that flies off the right side reappears on the left.

### Step 5: draw each boid as an oriented triangle

The boid's heading angle comes from `Math.atan2(vy, vx)`. We rotate a small triangle to point in that direction and color it by heading plus speed using the `hsl` helper from the shared library.

The draw loop runs every animation frame via `useAnimationFrame`, which handles visibility pausing and respects `prefers-reduced-motion`.

## Try this

- Click **New flock** to reseed with a different starting arrangement. Same rules, different starting point, different personality.
- Notice how the flock splits and rejoins when it encounters a tight cluster. No one decided to split — it falls out of the separation rule.
- The edges are toroidal: boids wrapping off one side see boids near the opposite edge as neighbours, so the flock stays coherent across the boundary.

## What to remember

Three local rules (separate, align, cohere) applied to every agent at every frame produce global flock behaviour with no central controller. That is emergence. The same principle explains how real birds and fish school, and it is used in production film, game AI, and swarm robotics.
