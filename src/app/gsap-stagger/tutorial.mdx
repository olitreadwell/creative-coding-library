# Tutorial: Stagger Grid

By the end of this tutorial you will understand what the `stagger` property does and how to predict the time it takes for the wave to reach the last tile.

## Predict

The sketch uses 96 tiles (12 columns by 8 rows) and a stagger delay of 0.045 seconds between each tile starting.

The center tile starts first. The corner tiles start last. How many seconds do you think pass between the center tile starting and the last corner tile starting? Round to the nearest second.

## Run

1. Open the sketch and count slowly as the wave travels from the center to the corner. See how close your estimate was.
2. Watch the wave reach an outer tile. Note that the tile is already midway through its animation before the very last corner tile has started.
3. Watch the animation reverse. The corners return first, then the center returns last.
4. Time the full forward-and-back cycle. It takes several seconds to complete.

## Look closer

- The `stagger` object includes `from: "center"` and `grid: [8, 12]`. GSAP uses those values to compute which tile starts first and how delays increase outward.
- Each tile animates to `scale: 0.45` and `rotation: 180`. These are the only changes. The ripple effect is entirely due to the staggered start times.
- `repeat: -1` means the timeline loops forever. `yoyo: true` means it plays forward, then in reverse, then forward again.
- The animation is scoped using `gsap.context()` with a ref to the outer div. This prevents GSAP from selecting `.stagger-tile` elements from other parts of the page.

## Break it

- Try changing `each: 0.045` to `each: 0.01` in the source code. The wave should move much faster, almost all at once.
- Try `each: 0.12`. The wave slows to a crawl. The full cycle takes much longer.
- Change `from: "center"` to `from: "start"`. The wave should begin at the top-left corner instead.
- Change `ease: "sine.inOut"` to `ease: "linear"`. The motion becomes mechanical and even-paced.

## Recap

Stagger is just a delay: each tile's start time is offset by a fixed amount from the previous tile. One simple animation (scale and rotate) applied to 96 tiles with increasing delays produces a wave, without any wave code.
