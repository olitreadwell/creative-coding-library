# HSL Palette

An interactive color tool that generates matching color sets from a single base color, using harmony math.

Learners see why HSL (hue, saturation, lightness) makes color arithmetic easier than RGB, and how color harmony works as geometry on a circle.

## What you see

- A row of color swatches that update as you move the sliders.
- Five harmony scheme buttons: complementary, analogous, triadic, tetradic, and monochromatic.
- Clicking any swatch copies its hex code to your clipboard.
- The readable text on each swatch switches between black and white based on lightness.

## What it teaches

- **HSL:** hue (0 to 360 degrees) sets the color name, saturation sets how vivid it is, lightness sets how dark or bright.
- **Color harmony:** adding fixed offsets to a hue produces color relationships that reliably look good together.
- **Contrast:** text color is chosen by lightness alone. Lightness above 55% gets black text; below 55% gets white.
- **Circular arithmetic:** hue wraps around 360. Adding 180 to any hue gives its exact opposite color.

## Try this

- Set saturation to 0. Every scheme shows shades of grey because there is no hue to rotate.
- Choose "Triadic" and slowly drag the hue slider. Watch all three swatches stay 120 degrees apart as the group rotates.
- Click any swatch and paste the hex code into another design tool.
