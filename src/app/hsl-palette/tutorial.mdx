## How it works, step by step

The app has two parts: a math layer (`palette.ts`) that computes colors, and a UI layer (`play/page.tsx`) that shows them. Here is how each piece fits together.

### Step 1: represent a color as HSL

The `@/lib/creative/color` library exports a small `hsl()` constructor. It takes three numbers and returns a typed `Hsl` object.

```ts
import { hsl } from "@/lib/creative/color";
import type { Hsl } from "@/lib/creative/color";

// hue: 210 degrees (a cool blue)
// saturation: 0.70 (70% vivid)
// lightness:  0.50 (middle brightness)
const base: Hsl = hsl(210, 0.7, 0.5);
```

Hue is in degrees (0–360). Saturation and lightness are fractions (0–1). Having a typed object makes the rest of the code readable and safe.

### Step 2: compute harmony offsets

`generatePalette` takes a base color and a scheme name. For most schemes, it rotates the hue by fixed offsets. For monochromatic, it steps through five lightness values while keeping the hue fixed.

```ts
const HUE_OFFSETS = {
  complementary: [0, 180],
  analogous: [-30, 0, 30],
  triadic: [0, 120, 240],
  tetradic: [0, 90, 180, 270],
  monochromatic: [0, 0, 0, 0, 0], // overridden by lightness steps
};

export function generatePalette(base: Hsl, scheme: Scheme): Hsl[] {
  if (scheme === "monochromatic") {
    const STEPS = [0.15, 0.3, 0.45, 0.6, 0.75];
    return STEPS.map((l) => hsl(base.h, base.s, l));
  }
  return HUE_OFFSETS[scheme].map((dh) => shift(base, dh, 0, 0));
}
```

`shift` is a helper from the color library that adds to hue and wraps it around 360. So `shift(base, 180, 0, 0)` gives you the exact opposite color.

### Step 3: pick readable text for each swatch

Each swatch button shows a hex label. The label needs to be readable against the swatch's background color. The rule is simple: if lightness is above 55%, the background is light, so use black text. Otherwise use white text.

```ts
const THRESHOLD = 0.55;

export function readableText(c: Hsl): "#000000" | "#ffffff" {
  return c.l >= THRESHOLD ? "#000000" : "#ffffff";
}
```

This keeps contrast acceptable across all hue and saturation values.

### Step 4: convert HSL to hex for display and copy

The browser needs hex codes for clipboard output. The color library provides two conversion helpers: `hslToRgb` turns the `Hsl` object into `{ r, g, b }` (each 0–1), and `rgbToHex` turns that into a `#RRGGBB` string.

```ts
const hex = rgbToHex(hslToRgb(color)); // e.g. "#3b82f6"
```

For the swatch background, `hslString(color)` returns a CSS `hsl(...)` string, which the browser renders directly.

### Step 5: the UI

The UI has three sliders (hue, saturation, lightness) and five scheme buttons. All state lives in the top-level component. Every change recomputes the palette from scratch. Because the math is fast (a handful of additions), this is fine with no memoization.

Each swatch is a `<button>` so it is reachable by keyboard. Clicking writes the hex to the clipboard using `navigator.clipboard.writeText`. A short "Copied" confirmation replaces the label for 1.5 seconds.

## Try this

- Set saturation to 0. Now every scheme shows shades of grey. That is because there is no hue to rotate.
- Set lightness to 0 or 100. All swatches go black or white. Hue and saturation have no effect at the extremes.
- Pick Triadic, then slowly drag hue. Watch the three swatches stay 120 degrees apart as the whole group rotates.
- Pick Complementary and adjust lightness. Notice how the readable text switches between black and white as you cross the 55% threshold.

## What to remember

- HSL makes color arithmetic readable. Rotating a hue by a fixed angle is one line of code.
- Color harmonies are just geometry on a circle. The math is not complicated; the visual results are.
- Readable contrast is a function of lightness, not hue. That one rule handles text color for all 360 possible hues.
