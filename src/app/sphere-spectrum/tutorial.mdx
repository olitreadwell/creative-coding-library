## How it works

### 1. One sphere, cached

A single `IcosahedronGeometry` is built once. For every vertex we cache its unit
direction (which way it points from the center) and its band (its latitude). At
rest the sphere just turns slowly.

```ts
const geo = new THREE.IcosahedronGeometry(1, DETAIL);
// per vertex: dir = normalize(pos); band = vertexBand(dir.y, 1, NUM_BANDS);
```

### 2. The microphone (on a click)

Nothing runs until you press Enable. Then we open the mic into a Web Audio
AnalyserNode and read its FFT each frame.

```ts
const analyser = ctx.createAnalyser();
analyser.fftSize = 2048;
analyser.smoothingTimeConstant = 0.65;
analyser.getByteFrequencyData(data); // data[i] in 0..255
```

### 3. Log-frequency banding (the important bit)

Raw FFT bins are linear, but pitch is logarithmic, so bass crowds into the first
few bins and treble sprawls across hundreds. We group the bins into a couple of
dozen bands with geometric edges, average each band, and add a treble shelf so
high frequencies survive.

```ts
const edges = logBandEdges(NUM_BANDS, usableBins); // edges[k] = round(1 * (hi/1)^(k/N))
const raw = bandLevel(data, edges[b], edges[b + 1]) * shelfGain(b, NUM_BANDS);
```

### 4. Gate, curve, envelope

A noise gate drops room tone; a perceptual curve lifts quiet bands; a per-band
attack/release envelope makes it punchy without jitter.

```ts
const target = Math.pow(clamp(gate(raw) * INPUT_GAIN, 0, 1), ENERGY_EXP);
env[b] = prev + (target - prev) * (target > prev ? ATTACK : RELEASE); // fast up, slow down
```

### 5. Displace and color the surface

Each vertex looks up its band's energy, pushes out along its cached direction, and
takes a cold-to-hot color. The audio slider scales the reaction.

```ts
const energy = clamp(env[band] * audioGain, 0, 1);
const r = BASE_RADIUS + energy * DISPLACE;
position.setXYZ(i, dir.x * r, dir.y * r, dir.z * r);
const hue = lerp(240, 0, energy); // cold blue -> hot red
```

After moving the vertices we call `geometry.computeVertexNormals()` so the lighting
follows the new shape, and flat shading gives the peaks crisp facets.

### Why refs, not state

The audio changes 60 times a second. Storing it in React state would re-render the
tree every frame, so the analyser, its buffer, and the per-band envelope live in
refs and the render loop reads them directly. State is kept for the controls only.

### Make it yours

- Raise **audio** for violent spikes, lower it for a gentle shimmer.
- Map the band to longitude instead of latitude, or to a noise field, for a
  different surface pattern.
- Swap the cold-to-hot ramp for frequency-to-hue if you want a fixed rainbow.
