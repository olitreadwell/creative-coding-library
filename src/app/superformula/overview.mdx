# Superformula

One equation, the Gielis superformula, that produces flowers, stars, gears, and blobs by changing four numbers.

Learners see how a single parametric formula in polar coordinates can describe a large family of shapes, from circles to complex polygons.

## What you see

- A closed curve drawn on the canvas, slowly breathing from a subtle auto-morph.
- Four sliders (m, n1, n2, n3) that reshape the curve in real time.
- Preset buttons (Flower, Star, Gear, Blob) that jump to named parameter sets.
- Drag any slider and watch the shape transform smoothly.

## What it teaches

- **Polar coordinates:** a point described by its distance from the center (radius) and its angle, rather than x and y.
- **Parametric formula:** the superformula takes one angle and returns one radius. Sampling it at 720 angles and connecting the dots produces the shape.
- **Parameter space:** four numbers control the formula. Integer values of `m` produce symmetric shapes; non-integer values break symmetry.
- **Auto-morph:** a slow sine wave added to `n1` each frame makes the shape breathe without touching the sliders.

## Try this

- Drag `m` from 1 to 10 slowly. A new petal (or point) appears at each integer.
- Set `n2` and `n3` to values above 6. The curve flattens into a polygon shape.
- Set `n1` below 1. The shape inverts and becomes star-like.
