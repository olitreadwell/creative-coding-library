# Tutorial: Webcam Mirror

By the end of this tutorial you will understand how each dot's radius is computed from camera pixel values and why the small sampling canvas keeps the animation fast.

## Predict

Luminance is `0.299 * r + 0.587 * g + 0.114 * b`, divided by 255 to normalize to [0, 1]. The result is then multiplied by the contrast slider before becoming the dot radius.

If a pixel has `r = 200, g = 200, b = 200` (a medium grey), what is its luminance before contrast? (Substitute the values and compute the weighted sum, then divide by 255.)

## Run

1. Click "Enable camera" and allow access.
2. Cover the lens briefly with your hand. All dots should become very small or invisible.
3. Uncover and point the camera at a bright light source (or a bright window). Watch the dots in that region grow large.
4. Drag "Dot size" from minimum to maximum. At minimum, the grid has many small dots showing detail. At maximum, it has few large dots showing abstraction.

## Look closer

- The camera is sampled into an offscreen canvas that matches the dot grid (for example, 60 columns by 40 rows). `getImageData` on that small canvas returns only the needed bytes. This is much faster than reading the full camera resolution.
- The horizontal flip is done before sampling: `ctx.scale(-1, 1)` after `ctx.translate(cols, 0)`. The dot grid itself is never flipped; the video is drawn flipped into the sample canvas.
- `cbRamp(adjusted, theme)` from the shared color library returns a color on the Okabe-Ito sequential ramp. That ramp avoids the red-green axis, so it reads correctly for the most common forms of color vision difference.
- When the component unmounts, `track.stop()` is called for every MediaStreamTrack. This turns off the camera indicator light.

## Break it

- Set "Contrast" to maximum and move in front of a uniformly lit wall. The dots should reach maximum radius even in areas that are not very bright.
- Set "Dot size" to minimum in a bright environment. The grid has so many tiny dots it approaches a photographic look.
- Try holding a piece of plain white paper. The dots in that area should all be maximum size (highest luminance).
- Point the camera at something with both very dark and very bright areas simultaneously. The contrast between dot sizes should be dramatic.

## Recap

`getUserMedia` requests the camera. Each frame, the video is drawn into a small canvas and pixel values are read back. Luminance converts RGB to one brightness number. Dot radius maps that brightness to a circle size. Three steps, any effect.
