# Tutorial: Webcam Mosaic

By the end of this tutorial you will understand how the same sampling pipeline drives both the glyph and circle modes, and where the only difference between them lies.

## Predict

For glyph mode, brightness is inverted before mapping to a character index (low brightness picks a dense character). For circle mode, brightness maps directly to radius (high brightness makes a large dot).

Why does glyph mode invert brightness but circle mode does not? Think about what a "dense" character looks like versus a "large dot."

## Run

1. Click "Enable" and allow camera access.
2. Start in ASCII mode. Hold your hand close to a bright background and watch the character density at the edge.
3. Switch to Circles. Notice the dot sizes change where the character density was high.
4. Switch to Blocks. Compare how the limited character set changes the smoothness of brightness gradients.

## Look closer

- The video is drawn into a canvas sized to `cols` by `rows` pixels (where col and row counts come from the cell-size slider). Each pixel in that canvas becomes one mark on the output canvas.
- The luminance formula is `(0.299 * r + 0.587 * g + 0.114 * b) / 255`. These are standard BT.601 coefficients used in video encoding.
- For glyphs, character density is measured once by drawing each character on a 16 by 16 canvas and counting opaque pixels. The measurement happens at startup, not each frame.
- The mirroring flip is applied to the sample canvas, not the output canvas. The video is drawn flipped, so the pixels read back are already in mirror orientation.

## Break it

- Try switching styles while the camera is running. The transition is instant because only the drawing step changes.
- Set cell size to maximum in ASCII mode. Each character represents a large area and the image becomes very abstract.
- Try writing your name on a piece of paper and holding it to the camera. The character contrast between dark ink and white paper should be visible.
- Swap the glyph string to contain only two characters (for example, " @"). The density sort still works, but you get only two levels of brightness.

## Recap

Three steps: sample the camera into a tiny canvas, compute brightness per cell, draw a mark. The mark is a glyph for ASCII and Blocks mode, and a circle for Circles mode. Only the last step differs between the three styles.
